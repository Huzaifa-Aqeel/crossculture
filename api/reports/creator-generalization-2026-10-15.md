## Demonstrated code corrections and remaining limits

- The worker previously requested only `target_type=place` despite Qloo movie/person capabilities. It now selects a small named type set from the seed's Qloo cultural tags (`movie` for narrative/film, `person` for sport, `artist` for music, otherwise `place`), carries exact ID/name/type/response ID, and retains place and tag directions for variety. Search-hit title ordering now recognizes type-specific substantive subject terms. This only changes lead ordering; the existing identity, named-pair resolver, frozen evidence and scorer remain unchanged.
- The LLM twice omitted Nike's supplied named people. The planner now creates one exact provenance-linked named direction if no non-place named direction survives validation. A tag-only direction that introduces an unsupplied capitalized multiword subject (the live example named Serena Williams without a named Qloo ID) is rejected. These final validator changes have focused positive/negative regression coverage, but were made after the last live Nike run and still need a live replay after the app rolling search window reopens.
- Neither new seed produced a source-supported scored recommendation. A24's bottleneck after retrieval was lack of an admitted bridge in the latest sampled evidence, plus two unresolved creator identities and one unverified market. Nike's initial run had incomplete multi-direction search at the app ceiling; the final replay completed all three directions but assessed only channels with unverified US market and still lacked an admitted bridge. These are evidence gaps or explicit execution limits, not negative cultural findings. A scoped future A24 run with optional captions can test whether an out-of-sample discovery hit contributes substantive source evidence without inflating representative frequency.
