## Focused planner correction

The model may still propose 3–5 diverse directions. Named directions now retain the exact Qloo name/ID/source and, when a suffix has more than three words, lose extra descriptors that narrow retrieval without another source. Automatic fallback covers a second supplied entity type when it is a recognizable cultural destination; it no longer forces a commercial hotel/apartment into a sports search. If only one useful named type remains, a second distinct supplied entity of that type can be searched while broad tag directions remain. Fallback follows Qloo order; it does not pick a previously successful candidate or cultural subject. Qloo directions are retrieval hypotheses only and do not assign C, R or G.
